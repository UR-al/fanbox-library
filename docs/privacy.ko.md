# 보관함의 데이터 처리

앱은 사용자가 선택한 파일, 작품 정보, 파일 지문과 보관 위치를 기기에 저장합니다. Windows의 폴더 연결은 원래 위치의 파일을 참조합니다. 앱에서 직접 가져온 파일과 색인은 Windows에서 현재 사용자의 `%LOCALAPPDATA%\FanboxLibrary`, Android에서 앱 전용 저장 공간에 보관합니다.

pixiv 로그인은 브라우저의 공식 FANBOX·pixiv 페이지에서 이루어집니다. 보관함은 pixiv 비밀번호나 브라우저 로그인 쿠키를 받지 않습니다. 공식 페이지를 방문하면 해당 사이트의 개인정보 처리방침이 적용됩니다.

기기 연결을 직접 열었을 때 선택한 작품의 메타데이터와 파일을 두 기기 사이에서 TLS로 전송합니다. PC의 인증서를 연결 코드로 확인하고, 해당 연결 코드로 요청을 인증합니다. PC에서 받기 권한을 켜면 연결한 폰이 선택한 파일을 PC로 보낼 수 있습니다. 앱 운영자가 중계하는 서버, 광고 SDK 및 사용 분석 SDK는 없습니다. 외부 보기 앱을 열면 선택한 파일을 해당 앱이 읽을 수 있습니다.

Android의 앱 데이터 지우기로 기기 안의 보관함을 지울 수 있습니다. Windows에서는 앱 종료 후 위 앱 데이터 폴더를 삭제하면 색인과 가져온 복사본이 지워집니다. 직접 다운로드한 파일과 연결한 작가 폴더는 원래 위치에 남습니다. 다른 기기로 이미 전송한 사본은 각 기기에서 관리합니다.
