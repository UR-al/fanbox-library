**件名**　第三者製 Android・Windows アプリでの投稿・添付ファイル取得について

pixivFANBOX ご担当者様

Android・Windows 向けに、利用者が保存した作品を端末内で整理・閲覧する非公式アプリを開発しています。Google Play と GitHub での配布を予定しています。現在は公式サイトをブラウザで開き、利用者が保存したファイルをアプリに取り込む方式です。

以下の二つの機能について、それぞれ実装・配布が認められるかご教示いただけますでしょうか。

1. 利用者が開いた一件の投稿で「この投稿を保存」を押すと、その利用者が閲覧できる原寸画像と添付ファイルの一覧を取得し、選択したファイルを本人の端末に保存する機能。
2. 利用者が選んだ一人のクリエイターについて、その利用者が閲覧できる過去の投稿と添付の一覧を取得し、端末に保存済みのものと照合したうえで、不足分だけを利用者の確認後に取得する機能。

ご案内可能な公式 API、第三者向けの認証方法、利用申請窓口、利用条件やアクセス頻度の上限がありましたら、併せてお知らせください。許可される範囲が機能ごとに異なる場合は、その範囲に合わせて公開を判断いたします。どうぞよろしくお願いいたします。

## 연동을 제공할 수 있게 됐을 때

| 기능 | 구현 전에 확인할 사항 | 검증 기준 |
| --- | --- | --- |
| ② 게시물 저장 | 한 게시물의 본문 순서, 원본·미리보기 구분, 첨부 식별자, 접근 권한, 사용자 인증 방식 | 열람 가능한 글에서 본문 순서와 파일 수가 일치하고 다운로드 실패·권한 변경이 개별 파일 상태에 표시된다. |
| ③ 작가 누락분 | 작가 목록 조회·페이지 이동 범위, 수정된 첨부 구분, 허용된 요청 빈도와 재시도 조건 | 허용된 글만 대조한다. 두 번째 실행에서 변경이 없으면 다운로드가 0건이다. 이전에 받은 작품이 수정되면 새 판본을 보존한다. |

공식 화면이나 확인된 제공 방식에서 원본 주소를 식별할 수 없는 이미지는 **원본 확인 불가**로 표시하고 공식 게시물 열기를 제공한다. 썸네일만 보이는 경우 사용자가 직접 선택해 보관할 수 있으며 **저해상도**로 구분한다. 불완전한 ZIP이나 중단된 전송은 완료로 집계하지 않는다. 공개 설명은 각 기능이 실제 검증된 범위에 맞춰 갱신한다.
